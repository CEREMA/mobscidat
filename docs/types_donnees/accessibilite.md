# Ressources sur les données sur l'accessibilité

L'accessibilité est un thème transverse qui concerne notamment les transports publics, la voirie et accessibilité des équipements publics.

Le site le plus pertinent est certainement le Point d’accès unique aux données d’accessibilité créé récemment :
https://accessibilite.data.gouv.fr/
